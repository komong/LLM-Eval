## 任务 1: 渲染层 - 添加「对比」按钮

位置：`.complexity` 徽章之前，与 `.scene` 并列。

## 任务 2: 新增 `openCompare(pid)` 函数
该函数负责：

1. 从 `allData` 中筛选出所有 `prompt_id === pid` 的记录
2. 跳过 error 的记录
3. 为每一条记录单独渲染输出（HTML / Markdown 分别处理）
4. 生成完整的对比页 HTML：
   - 顶部标题栏：Prompt ID + 场景名 + 「保存评分」按钮
   - 主体：CSS Grid 双列布局，每列一个模型
   - 每列包含：模型名、统计信息(latency/tokens/cost)、渲染后的输出内容、评分控件(星星+可用度+备注)
5. 通过 `window.opener` 回写评分：
   - 对比页中修改评分时，同步更新 `window.opener.allData`
   - 点击保存后，调用 `window.opener.markUnsaved()` 标记主页
   - 保存操作直接修改 `window.opener.allData`，关闭窗口后主页数据已是最新

## 任务 3: CSS 样式
