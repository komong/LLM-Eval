# 计费统计口径设置页面

## 核心数据模型
- `billing_config.json`: `{"display_currency": "USD", "exchange_rate": 7.25}`（1 USD = X RMB）
- runner.py 中模型增加 `price_currency` 字段（DeepSeek=RMB，MiniMax/Claude=USD）
- 所有记录存储 `cost_usd`（统一美元）+ `cost_native` + `price_currency`

## 任务清单

### 1. runner.py - 模型价格货币标记 + 双币种计算
- MODELS 每个配置增加 `price_currency: "RMB"` 或 `"USD"`
- `run_single()` 中计算 `cost_native`（模型原生币种），再通过汇率换算为 `cost_usd`
- 记录中保存 `cost_native`、`cost_usd`、`price_currency` 三个字段
- 汇率默认 7.25，后续从 `billing_config.json` 读取

### 2. score_server.py - 新增计费配置 API
- 新增 `GET /api/billing-config`：读取 `billing_config.json`，不存在则返回默认值
- 新增 `POST /api/billing-config`：保存用户设置的 `display_currency` 和 `exchange_rate`
- `/api/summary` 返回数据中增加 `cost_rmb = cost_usd * exchange_rate` 字段
- `/api/load` 透传每条记录的 `cost_usd`，前端自行换算

### 3. billing.html - 计费设置页面
- 独立的设置页面，路由 `/billing.html`
- 币种选择：USD / RMB 单选
- 汇率调整：数字输入框，实时显示换算示例
- 保存按钮，调用 `POST /api/billing-config`
- 导航栏含评分页、汇总页、计费设置三个入口

### 4. score.html + summary.html - 费用展示适配币种
- 页面加载时先请求 `/api/billing-config` 获取当前计费设置
- 根据 `display_currency` 决定显示 `$` 还是 `¥`
- USD 模式用 `cost_usd`，RMB 模式用 `cost_usd * exchange_rate`
- summary.html 顶栏导航增加「计费设置」入口

### 5. .qoder/plans 历史计划无关，不处理
