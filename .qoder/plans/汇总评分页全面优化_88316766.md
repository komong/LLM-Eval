# 汇总评分页全面优化

## Task 1: score_server.py - 后端支持模型显示开关
- `_get_models_config()`: 增加 `show_in_summary` / `show_in_score` 字段（默认 true）
- `_save_models_config()`: 支持保存完整配置对象（含 show_in_summary / show_in_score）
- `_summary()`: 按 `show_in_summary` 过滤返回的模型列表

## Task 2: summary.html - 汇总页优化
- 所有 th/td 改为 `text-align: center`，费用/Tokens 列保持右对齐
- 点击列头排序：为 `<th>` 添加 `onclick` 排序逻辑，支持数值升序/降序切换
- 模型简称映射函数：`deepseek-v4-flash`→`DS V4 Flash` 等
- `fmtCost()` 改为 `.toFixed(2)` 四舍五入

## Task 3: score.html - 对比预览页改进
- 高度铺满：`.cmp-container` 改为 `height: calc(100vh - 60px)`，`.cmp-output` 改为 `flex: 1; min-height: 0`
- 备注栏改为 `<textarea>` 支持多行输入
- 去掉"可用度"下拉，评分区只保留"质量评分"星级
- 去掉费用显示（`model-stats` 和 `cmp-stats` 中的费用）
- 图标改文字：🤖→模型、🔍→预览、📊→对比、💾→保存、⏱→耗时、📥→输入t、📤→输出t、💰→费用、📝→提示、⚠️→提示、❌→错误、💭→思考

## Task 4: score.html - 所有保存按钮颜色改浅色
- toolbar button: `background: #818cf8` hover `#6366f1`
- save-bar button: `background: #818cf8` hover `#6366f1`，shadow 调淡
- 对比预览窗口 save button: 同上
- `.saved` 状态: `background: #86efac`

## Task 5: models.html - 汇总模型显示管理
- 每个模型行增加两个小开关：「汇总页显示」「评分页显示」
- 通过 toggle 控制 `show_in_summary` / `show_in_score`
- POST 时发送完整配置对象 `{name: {enabled, show_in_summary, show_in_score}}`

## Task 6: 功能测试
- 启动 `python score_server.py`
- 验证汇总页：居中、排序、简称、费用2位小数
- 验证评分页：对比预览铺满、textarea备注、无可用度/费用、文字图标、浅色保存按钮
- 验证模型管理页：显示开关功能、保存后汇总页即时生效
