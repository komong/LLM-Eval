## 评分汇总页与默认展开

### Task 1: score.html - 默认展开所有 Prompt 分组
- 在 `render()` 生成 HTML 时，给 `.prompt-body` 添加 `open` 类，`.arrow` 添加 `open` 类
- 确保页面加载后所有模型卡片同时可见，用户可滚动对比

### Task 2: score_server.py - 新增 `/api/summary` 端点
- 读取 `results/` 下所有 `run_*.json` 文件
- 按模型+场景维度聚合：平均质量分、可用度分布、总 Token（input+output）、总费用、平均耗时、成功率
- 返回结构化 JSON 供前端渲染

### Task 3: summary.html - 独立汇总页
- 顶部导航：「评分页」链接跳转 score.html
- **模型总览表**：模型 | 测试次数 | 平均质量 | 均耗时 | 总费用 | 总 Token | 成功率
- **场景×模型质量矩阵**：横轴=模型，纵轴=场景，单元格=平均质量分
- **Token 消耗表**：模型 | 场景 | Input Token | Output Token | 总计
- 从 `/api/summary` 加载数据渲染

### Task 4: 验证
- 重启 score_server.py，访问汇总页确认数据正确展示
