# 左侧边栏统一布局重构 + 计费设置

## 目标
将 score.html / summary.html / models.html 及新建的 billing.html 统一为左侧边栏布局，以「模型评测系统」为品牌。billing.html 提供币种/汇率/Token Plan排除设置，summary 页和 score 页费用展示同步响应。

## 布局设计
```
┌──────────────────────────────────────────┐
│ 顶部栏: 模型评测系统                      │
├────────┬─────────────────────────────────┤
│ 评分    │                                 │
│ 汇总    │       右侧内容区                  │
│ 模型管理 │      (各页面原有内容)              │
│ 计费设置 │                                 │
├────────┴─────────────────────────────────┤
```

## billing_config.json 数据结构
```json
{
  "display_currency": "USD",
  "exchange_rate": 7.25,
  "exclude_token_plan": false
}
```
- `exclude_token_plan`: 勾选后，汇总页/评分页费用总计排除 Token Plan 模型（当前仅 MiniMax 系列）

## 任务清单

### 1. runner.py - 模型增加 is_token_plan 标记
- MODELS 中 minimax 增加 `"is_token_plan": true`
- 记录中透传此字段供后端过滤使用

### 2. score_server.py - 新增路由 + 费用过滤逻辑
- 添加 /billing.html、/models.html 路由
- GET /api/billing-config：读取 billing_config.json（不存在返回默认值）
- POST /api/billing-config：保存 display_currency / exchange_rate / exclude_token_plan
- /api/summary 返回中增加 billing 配置字段
- /api/summary 计算 total_cost 时按 exclude_token_plan 过滤
- 汇总数据中每个模型标记 is_token_plan

### 3. score.html - 重构为侧边栏布局
- 去掉顶部 nav，替换为左侧边栏 + 顶部品牌条
- 加载 billing config，费用按币种显示
- 侧边栏高亮「评分」

### 4. summary.html - 重构为侧边栏布局
- 去掉顶部 nav，替换为左侧边栏 + 顶部品牌条

### 5. models.html - 重构为侧边栏布局
- 去掉顶部 nav，替换为左侧边栏 + 顶部品牌条
