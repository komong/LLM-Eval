# 添加 MiniMax-M2.7 与模型选择前端页面

## Task 1: 修改 `runner.py` - MODELS 配置
- 新增 `"minimax-m2.7"` 模型条目：model_id=`MiniMax-M2.7`，价格沿用 M2.5 的 Token Plan 估算 ($0.20/$0.55)
- 所有模型添加 `"enabled": true` 字段，`deepseek-v4-flash-think` 设为 `false`
- 添加 `MODELS_CONFIG_FILE` 常量指向 `models_config.json`

## Task 2: 修改 `runner.py` - 读取配置并过滤
- 在 `main()` 开头读取 `models_config.json`（若存在），用其 `enabled` 值覆盖 MODELS 默认
- 过滤时只保留 `enabled: true` 的模型
- 跳过原因区分：无 API Key 显示"未配置 Key"，disabled 显示"已禁用"

## Task 3: 新建 `models.html` - 模型选择前端页面
- 展示所有模型列表：名称、provider、model_id、启用开关
- 调用 `/api/models` 获取配置，`POST /api/models` 保存
- 适配移动端，风格与 score.html / summary.html 一致

## Task 4: 修改 `score_server.py` - 新增路由
- 更新 `ALL_MODELS` 列表
- 新增 `GET /api/models`：返回所有模型配置（含 enabled 状态）
- 新增 `POST /api/models`：接收 `{model_name: true/false}` 写入 `models_config.json`
- 新增 `/models.html` 路由

## Task 5: 更新 `summary.html` 导航
- 导航栏增加"模型管理"链接指向 `/models.html`
